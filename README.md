# SmartRescue 2027 (SCERS)

**Smart City Emergency Response System**

A Java-based emergency response management system designed to support emergency reporting, ambulance coordination, and hospital attendance.

## Project Overview

SmartRescue 2027 aims to improve the coordination of emergency incidents by providing a structured workflow for reporting incidents, assigning ambulances, tracking response progress, and managing patient transfers to suitable hospitals.

## Core Features

- Emergency incident reporting and tracking.
- Incident verification and status management.
- Ambulance assignment and availability management.
- Ambulance team coordination.
- Hospital capacity and medical specialty checks.
- Patient transfer management.
- Data persistence and incident search.

## Technology Stack

- Java 23
- Apache Maven
- JUnit 5
- Git and GitHub
- JavaFX (planned GUI)

## Project Architecture

The application follows a layered architecture with separate responsibilities:

- **Model:** Core domain entities and business data.
- **Service:** Application business logic.
- **Repository:** Data access and persistence.
- **UI:** User interface.
- **Exception:** Custom exception handling.
- **Util:** Shared utility components.
